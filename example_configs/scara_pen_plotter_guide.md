# SCARA 写字机配置指南

## 📐 参数计算

### 1. 步进电机步数计算

#### 标准步进电机（1.8度/步）
- 每圈步数：200步
- 16细分：200 × 16 = 3200步/圈
- **步/度 = 3200 ÷ 360 = 8.89**

#### 0.9度步进电机
- 每圈步数：400步
- 16细分：400 × 16 = 6400步/圈
- **步/度 = 6400 ÷ 360 = 17.78**

#### 在配置文件中设置：
```yaml
x:
  steps_per_mm: 8.89  # 修改为你的实际值
```

### 2. 舵机脉宽调整

舵机的抬笔/落笔角度需要根据实际调整：

```yaml
z:
  motor0:
    servo:
      min_pulse_us: 500   # 最小脉宽（对应0度）
      max_pulse_us: 2500  # 最大脉宽（对应90度）
```

**调试步骤：**
1. 发送 `G0 Z0` - 舵机应该在抬笔位置
2. 发送 `G0 Z45` - 舵机应该在落笔位置
3. 如果方向反了，调整脉宽范围或使用 `G0 Z90` 作为抬笔

### 3. 工作空间计算

对于200mm臂长：
- **最大半径** = 200 + 200 = 400mm
- **工作面积** ≈ 502,654 mm² (π×400²)

**注意事项：**
- 避免让机械臂伸展到接近400mm的位置（容易抖动）
- 推荐工作半径：50-350mm
- 最佳工作区域：100-300mm

## ⚙️ 性能优化建议

### 1. 速度设置

```yaml
# 快速写字（大字）
max_rate_mm_per_min: 7200      # 20度/秒
acceleration_mm_per_sec2: 400

# 精细写字（小字）
max_rate_mm_per_min: 3600      # 10度/秒
acceleration_mm_per_sec2: 200

# 推荐：平衡速度和质量
max_rate_mm_per_min: 5400      # 15度/秒
acceleration_mm_per_sec2: 300
```

### 2. 分段长度调整

```yaml
kinematics:
  Scara:
    # 快速但可能有小抖动
    kinematic_segment_len_mm: 1.0
    
    # 平滑但计算量大（推荐）
    kinematic_segment_len_mm: 0.5
    
    # 超平滑，适合精细写字
    kinematic_segment_len_mm: 0.25
```

### 3. 电机电流设置

```yaml
# TMC2209示例
tmc_2209:
  run_amps: 1.2    # 写字机不需要太大电流
  hold_amps: 0.6   # 保持电流可以更低，减少发热
  
  # 如果机械臂抖动，可以增加电流
  # run_amps: 1.5
```

## 🐛 常见问题排查

### 问题1：坐标方向反了

**症状：** G0 X100 Y100 移动到相反方向

**解决：**
```yaml
motor0:
  tmc_2209:
    direction_pin: i2so.1:low  # 改为 i2so.1 或 i2so.1:low
```

### 问题2：舵机方向反了

**症状：** Z0应该是抬笔，结果变成落笔

**解决：**
```yaml
# 方法1：调整G代码
G0 Z90    # 抬笔
G0 Z0     # 落笔

# 方法2：调整舵机脉宽
servo:
  min_pulse_us: 2500  # 对调
  max_pulse_us: 500
```

### 问题3：画圆不圆

**原因：** 分段长度太大

**解决：**
```yaml
kinematics:
  Scara:
    kinematic_segment_len_mm: 0.3  # 减小分段长度
```

### 问题4：机械臂抖动

**原因：** 加速度太大或电流太小

**解决：**
```yaml
x:
  acceleration_mm_per_sec2: 200  # 降低加速度
  
motor0:
  tmc_2209:
    run_amps: 1.5  # 增加电流
```

### 问题5：工作空间边缘不可达

**症状：** 某些位置报错 "Target unreachable"

**原因：** 超出了SCARA的工作范围

**解决：**
- 检查坐标是否在半径400mm范围内
- 避免靠近机械臂中心（r < 50mm）
- 避免靠近最大半径（r > 380mm）

## 📏 坐标系统说明

### SCARA绝对角度坐标系

```
            Y轴 (正方向)
             ↑
             |
             |
    ---------|--------→ X轴 (正方向)
             |
             |
```

**关键角度：**
- θ = 0°: 大臂指向 -X 方向
- θ = 90°: 大臂指向 +Y 方向
- ψ = 0°: 小臂指向 -X 方向
- ψ = 90°: 小臂指向 +Y 方向

**典型位置：**
```gcode
G0 X0 Y0          ; 机械臂中心
G0 X200 Y0        ; 右侧200mm
G0 X0 Y200        ; 上方200mm
G0 X-200 Y0       ; 左侧200mm
G0 X0 Y-200       ; 下方200mm
G0 X141.4 Y141.4  ; 右上方200mm（对角）
```

## 📝 推荐工作流程

### 首次配置

1. 修改引脚配置匹配你的硬件
2. 上传固件和配置文件
3. 连接 FluidNC Web 界面或串口终端
4. 发送 `$H` 进行归位测试
5. 手动测试各轴运动

### 调试步骤

1. **测试X轴**：`G0 X90`（旋转90度）
2. **测试Y轴**：`G0 Y90`（旋转90度）
3. **测试舵机**：`G0 Z0` 和 `G0 Z45`
4. **测试移动**：`G0 X100 Y100`
5. **测试写字**：画简单的图形

### 生成写字G代码

使用软件将文字/图形转换为G代码：
- **Inkscape** + GCodeTools插件
- **LaserGRBL** (可以用于写字机)
- **CAM软件** (如 Carbide Create, Fusion 360)
- **在线工具** (如 gcode-generator.com)

转换后需要：
1. 设置正确的Z值（抬笔/落笔）
2. 调整进给速度
3. 确保坐标在工作范围内
